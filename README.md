# SandSational

Browser game workspace split for frontend and backend development.

## Structure

- `frontend/` - Phaser 3 + TypeScript + Vite browser game client
- `backend/` - reserved for the Java Spring Boot service
- `docs/` - shared notes, API contracts, and planning docs

## Frontend

```powershell
cd frontend
npm install
npm run dev
```

The frontend expects the Java backend API to be available at `/api` during development.
